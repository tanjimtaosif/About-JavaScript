    - How to remove data - removeItem
    - How to update data - setItem, it will update the existing data if not created.
    - Local Stirage only expects string data but we can use JSON.stringify to convert array or objects to string then we can store in local Storage. and to get in natiral format data we have to use JSON.parse to convert data string format data to natural format

- Cookies 
    - Store the data in the cookies property, including closing the browser but it hold less amount of data then the local and session storage.
    - Nearly ~4kb data
    - Whatever data we store in the cookies, it will send the data on the server automatically 
    - document.cookie = "name = tanjim@gmail.com" it will hold the data until we delete this
